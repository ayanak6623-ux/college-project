# User Preferences & Rules

- **Strictly No Chrome Browser Testing / No Browser Subagent**: Never launch automated browser subagents to test the application.
- **Strictly No Playback Video Rendering**: Do not generate, record, or render browser session playback videos. The user tests the app directly in their own browser.
- **No Auto-Commit**: Do not run `git commit` or `git push` automatically without explicit user request.
